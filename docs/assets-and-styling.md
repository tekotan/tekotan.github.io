# Assets and styling

## CSS / SCSS

- Entry point: `assets/css/main.scss`.
- SCSS partials: `_sass/`.
  - `_base.scss`, `_layout.scss`, `_themes.scss`, `_variables.scss` control the theme core.
  - `_cv.scss` styles the CV layout.
  - `_distill.scss`, `_tabs.scss`, `_typograms.scss` support optional content types.
- Vendor CSS is stored in `assets/css/` (Bootstrap, MDB, academicons, jupyter themes).

## JavaScript

- Core scripts live in `assets/js/`.
  - `theme.js`, `common.js`, `search/`, `masonry.js`, `zoom.js`, `copy_code.js`, `tabs.min.js`.
- Search data is generated by Liquid in `_includes/scripts/search.liquid`.

## Images

- Primary images live in `assets/img/`.
- Front-facing usage (current):
  - `assets/img/prof_pic.jpg` for the homepage profile image.
  - `assets/img/grad1.jpg`, `assets/img/grad2.jpg`, `assets/img/grad3.jpg` in a news post.

## PDFs and other media

- CV PDFs: `assets/pdf/`.
- Demo media assets used by sample posts/projects:
  - `assets/audio/`, `assets/video/`, `assets/plotly/`, `assets/jupyter/`, `assets/bibliography/`.
